# 기존 /onboard-asis 호환

`.claude/commands/specode.md`를 읽고 `$ARGUMENTS`를 `onboard ` + 기존 인자로 바꾸어 실행한다.
인자가 있으면 통합 커맨드 helper가 사용법만 안내한다. --deep 옵션을 추가하지 않는다.
앞으로 `/specode onboard`를 쓰도록 안내한다. 기존 분석 방식 선택과 등록 전 합의 절차는 유지한다.
