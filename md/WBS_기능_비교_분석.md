## 2. 일반적인 WBS/간트 도구가 주로 제공하는 기능

| 분류 | 기능 | 설명 |
|---|---|---|
| 관계 | **선후행 의존관계(Dependencies)** | A 작업이 끝나야 B가 시작되는 관계를 화살표로 표시. FS/SS/FF/SF 등 유형 지원 |
| 관계 | **임계경로(Critical Path)** | 의존관계 기반으로 "이게 늦으면 전체 일정이 늦어지는" 경로를 강조 |
| 관계 | **마일스톤** | 기간이 없는 한 시점(배포일, 검수일 등)을 다이아몬드 마커로 표시 |
| 진행 관리 | **진행률 표시** | 막대 안/위에 %를 시각적으로 채워 보여줌 |
| 진행 관리 | **베이스라인(계획 대비 실제)** | 최초 계획 일정을 고정해두고 실제 진행과 나란히 비교 |
| 편집 | **드래그로 일정 조정** | 막대를 끌어서 시작/종료일, 진행률을 바로 수정 |
| 편집 | **Undo/Redo** | 편집 실수 되돌리기 |
| 뷰 | **확대/축소(일/주/월/분기)** | 프로젝트 길이에 따라 시간 단위를 바꿔가며 보기 |
| 뷰 | **오늘 표시선** | 현재 날짜를 기준선으로 표시 |
| 뷰 | **휴일/비근무일 표시** | 주말뿐 아니라 회사 지정 공휴일도 별색으로 표시, 일정 계산에서 제외 |
| 뷰 | **그룹/계층 보기** | 상위 작업 아래 하위 작업을 접고 펼치며 봄 |
| 자원 | **담당자별 업무량(리소스 로드) 뷰** | 특정 기간에 누가 얼마나 많은 작업을 맡았는지 과부하 여부 확인 |
| 자원 | **다중 담당자 배정** | 작업 하나에 여러 명 배정 |
| 협업 | **댓글/파일첨부** | 작업 단위로 논의·자료 공유 |
| 데이터 | **Export(PDF/이미지/Excel)** | 보고용으로 내보내기 |
| 데이터 | **Import(Excel/CSV/MS Project)** | 기존 일정 가져오기 |
| 커스터마이징 | **커스텀 필드/컬럼** | 우선순위, 태그 등 프로젝트별 컬럼 추가 |
| 필터/검색 | **다중 조건 필터·검색** | 담당자·상태·기간 등 복합 조건 |

## 3. 우리 `/wbs` 화면 현재 상태

| 분류 | 기능 | 상태 |
|---|---|---|
| 관계 | 선후행 의존관계 | ❌ 없음 — 데이터 모델 자체에 "작업 간 순서" 개념이 없음 |
| 관계 | 임계경로 | ❌ 없음 (의존관계가 없어 전제 조건 자체가 없음) |
| 관계 | 마일스톤 | ❌ 없음 — 전부 기간이 있는 일반 작업(task)으로만 그려짐 |
| 진행 관리 | 진행률 표시 | ✅ 있음 — 막대 하단 얇은 선. "상태별 색상" 토글로 완료/진행중/미시작/지연 4색 구분 |
| 진행 관리 | 베이스라인 | ❌ 없음 |
| 편집 | 드래그로 일정 조정 | ❌ 의도적으로 잠금(readonly) — 일정 수정은 단위업무/화면/기능 각자의 편집 화면에서 |
| 편집 | Undo/Redo | ❌ (편집 자체가 없어 해당 없음) |
| 뷰 | 확대/축소 | 🟡 부분적 — "좁게 보기" on/off 2단계뿐, 일/주/월 같은 진짜 줌 레벨은 없음 |
| 뷰 | 오늘 표시선 | ✅ 있음 |
| 뷰 | 휴일 표시 | 🟡 부분적 — 토/일만 표시, 회사 지정 공휴일은 없음 |
| 뷰 | 그룹/계층 보기 | 🟡 부분적 — 탭(단위업무/화면/기능) 안에서 2단(상위 라벨 → 항목)만. 탭을 넘나드는 진짜 계층(단위업무→화면→기능)은 없음 |
| 자원 | 업무량 뷰 | ❌ 없음 — 담당자 "필터"는 있지만 부하 확인은 PM 워치의 팀 부하 매트릭스가 별도로 존재 |
| 자원 | 다중 담당자 | ❌ 없음 (단위업무/화면/기능 모두 담당자 1명 구조) |
| 협업 | 댓글/첨부 | ❌ 없음 — 각 엔티티 상세 페이지에 별도 코멘트 기능 있음(클릭해서 이동은 됨) |
| 데이터 | Export | ❌ 없음 |
| 데이터 | Import | ❌ 없음(설계 자체가 이미 있는 데이터를 보여주는 화면이라 해당 없을 수 있음) |
| 커스터마이징 | 커스텀 컬럼 | ❌ 없음 — 작업명/시작일/기간 3개 고정 |
| 필터/검색 | 필터 | 🟡 담당자 단일 선택만. 상태·기간 조건 없음 |
| — | 우리만 있는 것 | ✅ 페이지네이션(20/50/100), ✅ 영업일 기준 기간 계산, ✅ 작업명 클릭 시 상세 이동 |

## 4. 개선 제안 (우선순위순)

### 1순위 — 적은 작업으로 바로 체감되는 것

1. **확대/축소(줌) 레벨 추가**
   라이브러리(`@svar-ui/react-gantt`)가 `zoom` prop으로 일/주/월 단위 전환을 기본 지원한다.
   지금은 "좁게 보기" on/off 2단계뿐인데, 3~4단계 줌으로 바꾸면 별도 UI 없이 스크롤/버튼으로
   자연스럽게 확대·축소된다.

2. **공휴일 표시**
   지금 주말만 빨간 배경 처리(`highlightTime`)하고 있는데, 같은 함수에 공휴일 날짜 목록만
   추가하면 된다. 다만 "공휴일 목록"을 어디서 관리할지(직접 입력 vs 공공 API 연동)는 결정 필요.

3. **Export(PDF/PNG)**
   프로젝트 다른 화면(문서실 등)에 이미 엑셀/PDF 내보내기 컴포넌트가 있어 그 패턴을 재사용하면
   된다. 간트는 특히 "보고용 캡처"로 많이 쓰이는 화면이라 우선순위가 높다.

4. **마일스톤**
   요구사항/단위업무에 "배포일", "검수일" 같은 시점성 데이터가 이미 있다면(또는 추가한다면)
   라이브러리가 `type: "milestone"`을 기본 지원하므로 구현 자체는 가볍다. 관건은 "무엇을
   마일스톤으로 볼지" 데이터 정의.

### 2순위 — 데이터 모델 확장이 필요한 것

5. **선후행 의존관계 + 임계경로**
   지금 스키마엔 "이 작업이 끝나야 저 작업이 시작된다"는 관계가 아예 없다. 이걸 넣으려면
   새 테이블(예: 작업 간 링크)과 편집 UI가 필요한 큰 작업이라, 실제로 순서 관리가 필요한지
   먼저 확인하는 게 순서로 보인다.

6. **커스텀 컬럼 선택**
   지금 3개 고정 컬럼을 체크박스로 켜고 끌 수 있게(담당자, 진척률 등 추가) — 막대 위 텍스트
   체크박스(작업명/진척률/시작/종료일)를 왼쪽 그리드 컬럼에도 적용하는 확장이라 상대적으로
   수월하다.

7. **상태·기간 필터**
   지금 담당자만 필터되는데, "지연된 것만", "이번 달 시작하는 것만" 같은 조건이 추가되면
   대형 프로젝트에서 실제로 자주 쓰일 기능이다.

### 3순위 — 신중히 검토할 것 (설계 방향과 충돌 가능)

8. **드래그로 일정 수정**
   지금은 "조회 전용"으로 의도적으로 잠가뒀다. 여기서 편집까지 열면 저장 API를 새로 만들고,
   단위업무/화면/기능 각자의 편집 화면과 정합성(동시 수정 충돌 등)을 신경 써야 해서 범위가 크다.

9. **베이스라인(계획 vs 실제)**
   라이브러리 PRO 전용 기능이라 무료 코어로는 못 쓴다. 직접 구현하려면 "계획 스냅샷"을
   저장하는 별도 데이터가 필요하다.

10. **업무량(리소스 로드) 뷰**
    이미 PM 워치에 팀 부하 매트릭스가 있어서, WBS에 새로 만들기보다 그 화면으로 연결하는
    링크 하나가 더 실용적일 수 있다.
